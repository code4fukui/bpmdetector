# bpmdetector

aubio音声処理ライブラリのWASM版であるaubiojsライブラリを使用した、リアルタイムBPM検出Webアプリです。

## デモ
~~https://code4fukui.github.io/bpmdetecor/~~ *(unavailable)*

## 機能
- マイク入力からのリアルタイムBPM検出
- 検出されたビートを点滅インジケーターで可視化
- 平均BPMと最近のビートタイムスタンプを表示
- 窓長、ホップ、サンプルレートなどの検出パラメータを調整可能

## 要件
このWebアプリはモダンWebブラウザで動作し、ユーザーのマイクへのアクセスを必要とします。

## 使い方
1. 「🎤 マイク開始」ボタンをクリックしてBPM検出を開始します。
2. 必要に応じて、画面上のコントロールを使用して検出パラメータを調整します。
3. 現在のBPMと最近のビートタイムスタンプが表示されます。
